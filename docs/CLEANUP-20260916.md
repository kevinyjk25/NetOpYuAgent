### 怎样运行测试

```bash
.venv/bin/python -m pytest -q
.venv/bin/python -m pytest -q --test-suite=historical
.venv/bin/python -m pytest -q --test-suite=all
```

第一条默认 current；第二条只测历史探索；第三条为提交／发布完整回归。CI 和 `scripts/netopyu-dsh retirement` 明确使用 all。分类名单是 [tests/suite_policy.json](../tests/suite_policy.json)，选择器与防误排规则在 [tests/conftest.py](../tests/conftest.py)，行为回归在 [test_suite_policy](../tests/test_suite_policy.py)。新文件默认 current；缺失、重复、非法或保护名单中的历史条目会拒绝收集。

本次完整收集为 **3,697 项：current 3,447＋historical 250**；历史组对应 24 个文件。旧诊断移除 4 项，其余原测试没有因分类而消失。文档检查现覆盖 `evaluation/README.md`，避免评测导航出现未校验的失效链接。

**分类不是裁剪正式安全门禁。** 混合文件含安全／正式门禁时整文件保留 current；例如 flow admission、Runtime A/B、public Skill DSH A/B、translation study 和 checkpoint。不得使用 historical 分类来隐藏测试失败。pytest 的通过率／数量是工程回归，不是转译准确率、Agent 收益或生产安全概率。
